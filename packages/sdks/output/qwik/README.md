# Builder.io Qwik SDK

This is Builder's Qwik SDK.

## Minimum supported version

The [`peerDependencies`](./package.json) permit **Qwik >=1.0.0**. This is an installation range, not an actively verified support minimum; see the [framework version matrix](../../README.md#framework-version-guidance).

## Mitosis

This SDK is generated by [Mitosis](https://github.com/BuilderIO/mitosis). To see the Mitosis source-code, go [here](../../).

## Feature Support

To check the status of the SDK, look at [these tables](../../README.md#feature-implementation).

## Getting Started

```
npm install @builder.io/sdk-qwik
```

Take a look at [our example repo](https://github.com/BuilderIO/builder/tree/main/examples/qwik) for how to use this SDK.
